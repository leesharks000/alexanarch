## (10) Lines of research, and which result most advances / most retreats the framework

**The eight lines** (`00-kernel.yaml:lines_of_research`):

- **Q1-anchor.** Is there an external or material anchor for the composition of any Pauline letter, or for the received form of Revelation? Advances if no anchor is found for either; retreats if an anchor places a Pauline letter before Revelation's received form.
- **Q2-collection.** Did a sevenfold Pauline church collection circulate before Revelation? Advances if none is evidenced; retreats if one is demonstrated, or if Revelation's architecture is shown to depend on one.
- **Q3-markedness.** Does the crown-of-life markedness finding survive a wider sweep? Advances if the cluster stays compressed in Revelation, elaborated elsewhere, without a better common antecedent; retreats if a securely earlier attestation reopens the common-source audit.
- **Q4-direction.** Which way does the work–toil–endurance triad run between Rev 2:2 and 1 Thess 1:3? Advances if a direction test favours expansion from Revelation; retreats if it favours abbreviation from Paul.
- **Q5-replication.** Does Revelation 12 realise the frozen operator under substrate-blind replication? Advances if independent scores meet the pre-set threshold; retreats if they fall below it.
- **Q6-shared-order.** Can the extant Apocalypse meet the one requirement it does not meet, the shared order of Matthew and Luke? Advances if the requirement is shown to be *assigned*, not met, by Q as well; retreats if the order is a documented property Revelation cannot supply.
- **Q7-economy.** Do the phenomena rung V explains have a more economical explanation in ordinary multiple authorship? Advances if the author-function reading is cheaper on a phenomenon; retreats if multiple authorship is cheaper on every phenomenon — rung V is then dropped and I–IV stand.
- **Q8-historiography.** Is there a sustained modern historical-critical treatment that distinguishes and tests the three levels of priority? Advances if none is found; retreats if one is found, which the record calls "a welcome correction."

**Which result most advances:** I read **Q1-anchor succeeding** (no external or material anchor for either Pauline composition or Revelation's received form) as the highest-value advance, because it is the load-bearing line for the framework's strongest surviving claim — absolute priority as a *priced hypothesis* — and it feeds the D row's status on both sides of the symmetric ledger. **Q5-replication succeeding** is the highest-value advance for the *executable* claim, since it would turn rung IV from a programme into a result. Either would most advance; the question of which is "most" depends on whether the framework's centre of gravity is chronological or generative, and the kernel places both at the priced hypothesis (priority) and the executed arrow (generation) respectively.

**Which result most retreats:** I read **Q1-anchor retreating** (an external or material anchor placing a Pauline letter before Revelation's received form) as the deepest retreat, because it defeats absolute priority at rung I/II on the framework's own stated condition. **Q7-economy retreating** (multiple authorship cheaper on every phenomenon) is the next-deepest: it drops rung V and, with it, rung VI — but not I–IV, which the kernel explicitly keeps standing (`INV-3`, `rungs[4].defeat`, `rungs[5].defeat`). So Q1 is where the framework's absolute claim lives or dies; Q7 is where its contingent claim does.
