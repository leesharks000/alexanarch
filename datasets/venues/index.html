Venues

The canonical store behind datasets/journals. Eight venue records — seven chartered journals and one province — and seven issue cards.

Canonical authority

These files are canonical. venues.json beside them is a generated projection, and so is everything under /datasets/journals/. Edit a record and run scripts/build_venues_index.py; --check fails on drift, and scripts/check_venue_links.py fails when a charter AXN, record URL or assigned deposit stops resolving.

The records

Each record carries the venue's scope, claim terms, editorial slate, charter locator, press, identifiers and inaugural issue. The schema is generous by rule: every field is declared even where empty, because a field can be null, but a datum without a field ends up not existing.

The issue cards

Modelled on the heteronym identity cards. An issue is an ordered selection with an argument, which membership data cannot hold — so each card carries structure, method, rationale, and per item a section and the editor's note on why it sits there.
