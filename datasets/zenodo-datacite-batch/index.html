Zenodo / DataCite Batch

The DOI Resolution Index v3.7.2 packaged alongside the DataCite metadata backup captured before the 2026-06-19 Zenodo account severance. Together these two instruments constitute the empirical foundation for the EA-EROSION-01 census and the outward-facing EA-REMEDIATION-01 whitepaper.

What this batch is. On 2026-06-19, the Zenodo account under which 871 DOIs had been minted to Lee Sharks was terminated by CERN. The DOI resolver (v3.7.2, deposit #4) maps every severed DOI to a valid alexanarch resolution target where possible — 96% coverage — and provides structured fallback paths for the remainder. The DataCite batch captures the metadata state as it existed at DataCite before the severance propagated to the public API. Together they are the pre-severance reference frame: the resolver preserves the addresses, the DataCite batch preserves the metadata graphs.
