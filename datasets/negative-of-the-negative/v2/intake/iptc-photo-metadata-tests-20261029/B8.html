What Is Image Metadata? EXIF, IPTC and XMP Explained

Mac MetaImage Metadata EXIF IPTC XMP Editor

When you take a photo, the image contains much more than just pixels. Your camera or smartphone can also store information such as when the photo was taken, which camera and lens were used, camera settings, GPS coordinates, copyright information, keywords, and descriptions.

This information is known as image metadata or photo metadata.

Three of the most important metadata standards you'll encounter are EXIF, IPTC, and XMP. Although they're often grouped together, they serve different purposes.

In this guide, we'll explain what image metadata is, what EXIF, IPTC and XMP mean, and why you might want to view or edit this information.

What Is Image Metadata?

Image metadata is information stored alongside the visual content of an image.

While the pixels determine what the photograph looks like, metadata describes information about the image.

Depending on the file and device, photo metadata can contain information such as:

  • Date and time the photo was taken
  • Camera manufacturer and model
  • Lens information
  • ISO
  • Aperture
  • Shutter speed
  • Focal length
  • GPS location
  • Photographer or creator
  • Copyright information
  • Title and description
  • Keywords and categories

Because metadata is separate from the image pixels themselves, many metadata fields can be edited without changing the visual appearance of the photograph.

What Is EXIF Metadata?

EXIF stands for Exchangeable Image File Format.

EXIF metadata is commonly generated automatically by digital cameras and smartphones when you take a photo.

It primarily contains technical information about the image and how it was captured.

Typical EXIF metadata includes:

  • Camera manufacturer and model
  • Lens model
  • Date and time
  • ISO
  • Aperture
  • Shutter speed
  • Focal length
  • Flash information
  • Image orientation
  • GPS coordinates

For example, if you want to know which camera was used to take a photograph or which aperture and shutter speed were selected, you'll usually find that information in its EXIF metadata.

Can EXIF Contain Your Location?

Yes. Smartphones and GPS-enabled cameras can store the latitude and longitude where a photo was taken inside its metadata.

This can be extremely useful for organizing a photo collection, but it can also be a privacy consideration when sharing images publicly.

Before publishing a photo online, you may therefore want to check whether it contains GPS metadata.

What Is IPTC Metadata?

IPTC refers to metadata standards developed for the professional exchange and description of media.

Unlike EXIF, which is heavily focused on technical capture information, IPTC metadata is commonly used to describe, organize and manage images.

It can include information such as:

  • Title
  • Description or caption
  • Keywords
  • Creator or photographer
  • Copyright notice
  • Credit
  • Source
  • Location information
  • Usage and rights information

IPTC metadata is particularly useful for photographers, journalists, publishers, agencies and image libraries managing large collections of photographs.

For example, a professional photographer can add their name, copyright notice and descriptive keywords directly to their images.

What Is XMP Metadata?

XMP, or Extensible Metadata Platform, is a metadata framework originally developed by Adobe.

XMP provides a flexible way for applications to store and exchange metadata.

It can contain descriptive and administrative information and can also be used by photo-editing applications to store information related to an editing workflow.

XMP metadata can be embedded directly inside compatible files or stored separately.

A separate XMP file located alongside an image is commonly called an XMP sidecar file.

For example:

DSC_0123.RAW DSC_0123.XMP

The original image remains unchanged while compatible software can use the XMP sidecar to store metadata or editing information associated with it.

EXIF vs. IPTC vs. XMP: What's the Difference?

The easiest way to understand the three is to think about their typical roles:

Metadata Primarily used for Examples
EXIF Technical capture information Camera, lens, ISO, aperture, shutter speed, capture date, GPS
IPTC Description, authorship and rights Title, caption, keywords, photographer, copyright
XMP Flexible metadata exchange and editing workflows Descriptions, rights, ratings, editing information, application-specific metadata

These standards can coexist inside the same image.

A single photograph might therefore contain EXIF camera information, IPTC copyright information and XMP editing or descriptive information at the same time.

Why Is Photo Metadata Important?

Metadata has several practical uses.

Organizing and Finding Photos

Dates, locations, ratings, descriptions and keywords can help applications organize large photo libraries and make images easier to find.

Understanding Camera Settings

Photographers can inspect EXIF information to understand how an image was captured.

For example, comparing ISO, shutter speed, aperture and focal length can be useful when studying your photography technique.

Copyright and Attribution

Photographers can use metadata fields to include information about the creator, copyright and usage rights.

Metadata shouldn't be treated as an infallible form of copyright protection because it can be removed or modified, but it provides useful information that can travel with the image.

Location and Privacy

GPS metadata can tell you exactly where a photograph was taken.

That's useful for travel photography and photo organization, but you may not always want to share that information publicly.

Checking and removing sensitive metadata before sharing certain photos can therefore be useful.

How to View and Edit Image Metadata on Mac

Some basic photo information can be viewed directly in macOS, but dedicated metadata editors provide access to a much larger number of fields.
