What is IPTC Photo Metadata?

* Definition: A universally accepted industry standard for embedding administrative, descriptive, and copyright data directly into image files. [[1](https://www.google.com/goto?url=CAESdwHrOzAVa6YL90vCdRk54bfdCqyuYvh4CEovCdFgLnEYnW3vbq09ZsykzLkAgXLUGErTkcuY4uCsxb8pXorV__XOQ0JcYHG2Kgd9ZbyoOqFJqcBn9xqzDUyjQakZoE014-xIBDq1rPZXnhrwS1gzyAN-Qx02xwej), [2](https://www.google.com/goto?url=CAESYgHrOzAVgRF_fxxfUoaWdjEmJnXOZUi2mo9AXD-jVEu2IjmL-Wvj_9DMkof04xcPAjsAtWDsUbxAgfu9s_ueEl-GBbSNqzO20Sw3PHeK1jaO3Xww-EWyREarSRCOFKNO33s5)]
* File Formats: Supported across formats like JPEG, TIFF, and PNG, using the [IPTC Core and Extension Schemas](https://www.google.com/goto?url=CAEScAHrOzAVamozPSLuGtmUTmGz7WwmcSatTV8gSXhP-9rIadeE0o5ppLComWGrJdrdV7r9w8ZPg5AcHt7iiTBh6iqnkKCyxuIZn7Zu32WsAykDeM_t3-KZ1Bf5tz_TdNJ6qLmpFvAlGMzKRlW10KxlAkU) as well as Adobe's XMP framework. [[1](https://www.google.com/goto?url=CAEScAHrOzAVamozPSLuGtmUTmGz7WwmcSatTV8gSXhP-9rIadeE0o5ppLComWGrJdrdV7r9w8ZPg5AcHt7iiTBh6iqnkKCyxuIZn7Zu32WsAykDeM_t3-KZ1Bf5tz_TdNJ6qLmpFvAlGMzKRlW10KxlAkU), [2](https://www.google.com/goto?url=CAESeAHrOzAVmh2LShS5MWI7zNanQK48Fy09v-FUYv2fnKOl9Q60zl7NWCKFzXzvAmw_B7hv4YRIkFhcV9ZArqAfLAqhCWvoKppUBtuwrHTa-1FfSdQFDP1Sw-D_tVVoLSju-14i-JNEDTa0OM5CTjm3leteOr04ZieTEQ)]
* Difference from EXIF: While EXIF focuses on technical camera data (shutter speed, ISO, lens settings), IPTC focuses on human-readable details like captions, keywords, and creator credits. [[1](https://www.google.com/goto?url=CAESfwHrOzAV4OaxjMInbnBsTfDNBVPuyfZx3qG_QPAwuA6FUkdWDuhM_hqnEFFXY5HEDP898osmd5eS4Ij5o2s2AvZGP6VBhWtbdEhffhRZTSpOgTS09pI8vTSo1CkN7JlsP-t5GgAO74Oqz2ULN4-gv533xk5Hge5IQL3z66HzPaE)]

Main Metadata Categories

* Descriptive: Includes Alt Text, Headline, Description/Caption, Keywords, and Subject Codes.
* Administrative: Tracks Creation Date, Digital Source Type, Image GUIDs, and registry IDs.
* Rights & Ownership: Stores Creator (Photographer), Copyright Notice, Licensor, and usage terms.
* AI & Content Provenance: Recent standards (such as version 2025.1) include fields for AI System Used, AI System Version, AI Prompt Information, and AI Prompt Writer Name.
