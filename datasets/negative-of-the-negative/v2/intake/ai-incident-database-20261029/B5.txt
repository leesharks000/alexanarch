# ⚠️ AI Incidents, Failures & Controversies Database

### 32 verified incidents · 29 companies · 13 countries · 24 columns — Every major AI failure, documented

---

## 📌 Why This Dataset?

AI incidents surged **56.4% in 2024 alone** (Stanford HAI AI Index 2025). From deepfakes influencing elections to autonomous cars killing pedestrians, AI failures are no longer hypothetical — they're happening at scale.

This dataset is a **curated, analysis-ready compilation** of the most significant real-world AI incidents, sourced from verified databases and news reports. Every single entry is a real, documented event.

---

## 📊 Data Sources

| Source | What We Used |
|---|---|
| **AI Incident Database (incidentdatabase.ai)** | Primary incident records and AIID identifiers |
| **MIT AI Incident Tracker (airisk.mit.edu)** | Severity classifications, harm taxonomies |
| **Stanford HAI AI Index 2025** | Incident trend data and statistics |
| **AIAAIC Repository** | Cross-verification of incidents |
| **Verified News Reports** | CNN, Reuters, BBC, NYT, SCMP, TechCrunch |

## 📋 Column Descriptions (24 columns)

| Column | Type | Description |
|---|---|---|
| `incident_id` | str | AIID reference ID or custom ID |
| `date` | date | Date of incident or public disclosure |
| `year` / `month` / `quarter` | int | Time dimensions |
| `title` | str | Descriptive incident title |
| `company` | str | Company/organization involved |
| `ai_system_type` | str | Type of AI system (LLM, Autonomous Vehicle, etc.) |
| `harm_category` | str | Specific harm type |
| `harm_domain` | str | MIT taxonomy domain (Safety, Fairness, Privacy, etc.) |
| `harm_severity` | str | Critical / High / Medium / Low |
| `sector` | str | Industry sector affected |
| `country` | str | Country where incident occurred |
| `description` | str | Factual summary of the incident |
| `people_affected_estimate` | int | Estimated number of people affected |
| `financial_impact_usd` | float | Estimated financial damage in USD |
| `regulatory_response` | str | Government/regulatory actions taken |
| `technology_type` | str | Underlying AI technology |
| `ai_task` | str | AI task that failed |
| `root_cause` | str | Identified root cause of failure |
| `resolved` | bool | Whether the issue has been resolved |
| `legal_action_taken` | bool | Whether lawsuits or charges were filed |
| `involved_fatalities` | bool | Whether deaths occurred |
| `source_url` | str | Primary source URL |

## 🧪 Analysis Ideas

1. **Incident Timeline Visualization** — How are AI failures accelerating year over year?
2. **Harm Taxonomy Treemap** — Which types of AI harm are most common?

## 📝 Data Notes

- Every incident is **real and publicly documented** — no synthetic data
- Incident IDs starting with "AIID-" reference the AI Incident Database (incidentdatabase.ai)
- Incident IDs starting with "REAL-" are compiled from multiple verified news sources
- Descriptions are original summaries based on multiple public reports
- Financial impact figures are estimates based on reported losses, fines, and market cap changes
- `people_affected_estimate` is null when the number cannot be reasonably estimated
- Dataset is a curated subset — the full AIID contains 1,300+ incidents
- Severity ratings are based on MIT AI Incident Tracker methodology
