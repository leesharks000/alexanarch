Papers with Code shut down in July 2025.
If you searched for papers with code shutdown Meta July 2025, Papers with Code shutdown date, or Papers with Code shut down 2025, the short answer is: Meta retired Papers with Code in July 2025, with the public shutdown observed around July 24-25, 2025.

§ 01 · Timeline
What happened to Papers with Code?
2018
Papers with Code became the default ML leaderboard map.
The service connected papers, code, datasets, tasks, methods, and SOTA tables in one browsable registry.
2025-07
Meta shut Papers with Code down.
The practical shutdown date window users cite is July 24-25, 2025. The old benchmark registry stopped behaving as a maintained public destination.
After shutdown
The domain no longer replaced the old product experience.
Users looking for paperswithcode.com were pushed toward Hugging Face, while the comprehensive task-based SOTA tracker and public API were no longer maintained.
Now
Use archives for history and maintained services for live decisions.
Historical PWC data remains useful, but production model choice needs dated, sourced, refreshed benchmark evidence.
§ 02 · Data and API
Where did the old Papers with Code data go?
The old site and API did not continue as a maintained public registry. Historical dumps remain useful for reconstruction, citation checks, and migration work, but they should not be treated as a current leaderboard.

Use the GitHub archive for old papers, datasets, methods, and evaluations.

The old paperswithcode.com/api/v1 endpoints are not the live replacement path. See the migration-oriented API page instead.
