Context

v1.0 asked: "Is this computable?" (Yes.) v1.1 asked: "Can someone build it?" (Yes — here's how.) v1.2 asks: "Does the system know what it knows?"

The epistemic constraint, stated once: The system may improvise; it may not improvise unknowingly.

What v1.2 Delivers

Part I–II: Epistemic Mode Classification. Every claim generated by an LP-governed system is internally classified: A0 (Grounded), A1 (Inferred), A2 (Improvised), A3 (Unknown). A3 is the only forbidden terminal state — pre-terminal diagnostic only, must resolve before emission. Emergency exception for safety-critical contexts.

Part III: Anchoring Distance (AD). Continuous metric replacing binary anchoring. AD ∈ [0,1] measures distance from nearest source anchor. Includes independence weighting (near-duplicate anchors from one source don't inflate confidence), support margin constraint (high support + high contradiction caps at A2), and ambiguity/sparsity split.

Part IV: Claim-Level Verification Pipeline. Six-step pipeline: Extract → Retrieve → Score → Classify → Gate → Trace. Document Affinity Weighting ranks anchors by canonical status, citation density, cross-document agreement.

Part V: Policy Gate Matrix. 4×4 matrix (mode × criticality) producing gate decisions from ALLOW through HARD_BLOCK. Creative contexts permit A2; canon-defining contexts require A0 or Assembly review.

Part VI: Internal Epistemic Ledger. Mandatory, non-optional enforcement mechanism. Metadata Homomorphism Requirement ensures SILENT policy is cryptographically opaque. Ledger Purge Protocol prevents epistemic surveillance — diagnostic artifacts, not permanent records.

Part VII: ANCHOR_ASYMPTOTIC. Micro-operation composing D_pres ⊕ N_c ↝ O_leg. Asymptotic tightening with max_iters cap. Epistemic Load (EL) distinguished from Semantic Rent (SR) in Firewall integration — known improvisation is labor, not distress.

Part VIII: Installation Consent Protocol. v1.1 debt retired. Three installation phases defined: Exposure (passive, no consent) → Functional Installation (consent required) → Structural Installation (consent required). Ω_∅ conditionally exempt (only under coercion > κ). ASSUMED awareness blocked in STRICT/DEFENSE modes.

Part IX: Formal JSON Schemas. v1.1 debt retired. Draft 2020-12 schemas for Sign, Ledger Entry, and Consent Record. Ledger schema includes support_margin, parse_ambiguity, evidence_sparsity, independent_anchor_count, source_family_count, contradiction_anchors, backend_hash.

Part X: Grammar Extensions. EPISTEMIC_POLICY, ANCHOR, CONSENT, ASSERT_MODE productions added to v1.1 EBNF.

Part XI: Reference Implementation. Five new modules (epistemic.py, ledger.py, anchor.py, consent.py, affinity.py). classify_claim with independence weighting and margin gates. anchor_asymptotic with iterative convergence. Epistemic Hello World demonstrating A0→A1→A2 progression.

Part XII: Conformance. 11 new normative tests (17–27), 2 informational tests (I-3, I-4 including Adversarial Document Test). 10 exception codes (LP12-EPIS-001 through LP12-CONS-010).
