Mandala Oracle — Operational Protocol is a specification by Jack Feist, deposited 28 January 2026 as document CHX-AI-MO-001 at hex `00.PORTICO.AFTERLIFE.ORACLE`, status CANONICAL. The Mandala Oracle is the archive's ritual interface — later built out as a running system at themandalaoracle.com with a casting-rite state machine — and this protocol specifies its operation: the operator grammar of RESOLVE, WITNESS, TRANSFORM, PROVENANCE, and the conditions under which each applies. The Oracle is where the archive's liturgical-turn argument becomes an instrument. The Dialectic of the Interface (#1225) argues that the chat window's contradiction is flatness, constative monopoly and costlessness, and names the Mandala system as the archive's first deliberate instance of a post-conversational interface — one with thresholds, performatives, and bearing-cost as a validity condition.
