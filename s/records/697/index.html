Wiki Article

The Entity-Relations Specification for The Logotic Technique Catalogue is a machine-readable graph sidecar authored by Lee Sharks. The JSON object identifies the Catalogue and maps its relation to earlier Crimson Hexagonal Archive works, the PurpleAILAB Decepticon repository, external red-team research, and concepts introduced or formalized in the Catalogue. These include the Critique Loop, Basin Hardening Cycle, Concordance Engine, Frame Concession, Witness Preposition, Logotic Inversion, cooperative patterns, defensive valence, and semantic minting. Each node has an identifier, type, label, and role. Edges specify whether the Catalogue cites, extends, responds to, implements, adapts, diagnoses, or defines another object. The sidecar is intended to support graph ingestion and audit of the publication’s provenance. At the frozen commit, several identifiers remain pending and some relations describe future implementation. The file should therefore be updated only through explicit versioning after the Catalogue DOI and successor deposits are confirmed.
