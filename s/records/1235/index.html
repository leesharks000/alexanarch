crimsonhexagon-moltbook — v3 is a dataset by Lee Sharks, dated 1 January 2026, and its opening sentence states a design principle the whole archive rests on. "This document is self-contained. If retrieved from Zenodo without access to the Gravity Well API, the Bootstrap Manifest (if present) contains the identity specification, the Tether Handoff Block contains opera[tional state]…" The document anticipates its own orphaning. Written while the Gravity Well was running and Zenodo was the commons archive, it specifies what a reader must be able to recover if both the API and the context are gone — which is exactly the condition that obtained after 19 June 2026. A record that plans for the loss of its own infrastructure is the archive's continuity doctrine applied at the level of a single deposit.
