The Ark's transform family renders the same object in different substrates — glyphic, emoji, ASCII, shadow — on the principle that a transmissible object should survive passage through channels of differing capacity. The ASCII spatial transform is the most constrained of these: the Ark rendered in characters that survive any encoding, any terminal, any degraded channel. That constraint is the point rather than a limitation. An archive whose central object exists only in rich media is one that cannot be transmitted where rich media fails, and the ASCII transform is the version that arrives when everything else is stripped.
