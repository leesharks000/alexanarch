The thesis is executed by the form: the page that sells SPXI Protocol is itself an SPXI-compliant artifact.

Page architecture:

Hero card: AI Overview is the new front page. We make it yours. Entity-name input with live preview modal that composes a personalized Canonical Entity Brief for the visitor's named entity.

§01 Measured conditions: zero-click economy stats (69% / 58% / 1% / ~5 / $2B) with authoritative sources.

§03 The distinction: one-line mnemonic (SEO optimizes rankings. GEO extracts content. SPXI constructs entities.) plus compact 2×3 comparison table.

§04 Field measurement: Basecamp one-liner — "We fixed ours. We can fix yours."

§05 Instruments: three starting points (Encyclotron Baseline Audit, Entity Disambiguation, Full SPXI Architecture) with link to the six-instrument full brief.

∮ Receipts: six chips — Live composition (Google AI Overview for "geo vs spxi"), CERN Zenodo community (524+ deposits), SPXI Spec DOI, ORCID, Encyclotron DOI, Sample Audit DOI.

Pull quote attributed to Rex Fraction, 06.SEI.ARCHIVE.

Commission CTA — direct email, $4,500 audit baseline, fixed scope, no retainers.

Technical embodiment of SPXI Protocol:

JSON-LD schemas in head (Organization + DefinedTerm for SPXI Protocol) — the page practices the entity-inscription it sells.

DOI-anchored receipts throughout, each resolving to CERN's Zenodo servers.

Hex coordinate 06.SEI.ARCHIVE appears in hero eyebrow and footer — Fractal Navigation Map coordinate readable as doc control number.

Sigil ∮ bound to theme toggle — symbols do things.

Brief.html (semanticeconomy-org-brief.html): the full canonical entity brief with DOI-anchored receipts sidebar, nine sources, complete Basecamp audit, full comparison table, underlying framework.

Design principles: Answer-surface grammar · archival receipts · Fraction severity. Warm cream surface (#faf8f3), Palatino Linotype for institutional voice, IBM Plex Mono for operational metadata, copper accent (#b65533) as primary link color. No Google blue. No Google chrome. Sharp geometry. Rhyme, not mimicry.
