Description

This record points to a machine-readable backup created from a complete inventory of 1,817 DOI strings associated with the Crimson Hexagonal Archive. Its purpose was to preserve recoverable DataCite metadata after Zenodo removal and public metadata loss. The preserved fields include titles, creators, name identifiers, subjects, descriptions, dates, rights, resource types, and related-identifier relations. These fields can contain substantial intellectual content and citation structure, not merely administrative tags. The body documents three collection routes: ORCID search, creator-name searches across heteronymic surfaces, and individual DOI lookups. It links the JSON dataset and a companion empirical paper analyzing the public API results. The body contains a decisive arithmetic defect. It reports 963 metadata records recovered and 871 stripped from an inventory of 1,817, but 963 + 871 = 1,834. Its query-method subtotals also sum to 963. The later corrected audit in #868 reports 946 preserved + 871 absent = 1,817. The difference is seventeen records. The replacement description must therefore identify #867 as the initial backup pointer with stale or erroneous summary counts and use the dataset itself plus #868’s reconciled classification for authoritative totals. The body also claims equivalent metadata for the 871 records is permanently lost. That is too absolute. It was absent from the observed public DataCite API and may survive in local backups, repository internals, other APIs, exports, caches, mirrors, or later restoration. The dataset’s preservation value remains substantial without a universal-loss claim.

Preservation Note

## Preservation Note

Some metadata in this backup exists only in these DataCite records:

  • Subjects (keywords) — including poems and critical terms typed directly into Zenodo's keyword field
  • Descriptions — including critical apparatus, poem framings, and scholarly abstracts up to 3,738 characters
  • RelatedIdentifiers — the encoded citation graph between works (IsVersionOf, References, Compiles, Continues, IsPartOf)
  • Creator attributions with ORCID and affiliation data

For the 871 stripped DOIs, equivalent metadata is permanently lost.
