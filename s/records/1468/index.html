0. The one blocker

Everything downstream waits on a single computation.

W-1 · FULL-STACK SPXI COMPUTATION. One transcript rendered as a complete measurement object: raw evidence → attribution atoms → PER-M/C/D → PER, Ω, α_T, Π_d^{w+} → ρ_T → DSL span classes → Β → classification → control.

All four assembly reviews arrived at this independently. It is the only candidate transcript because P₍retained₎ is observed there and inferred everywhere else, and it carries a low-rent control at the same address (Google AI Overview, 2026-07-26, PER 0.25).

It unblocks: Β as a citable number · M/C/D's worked instance · ρ_T's null-discipline made visible · the first conformance fixture · the template both surfaces grow from.

Do not expand the theory further until this exists.
