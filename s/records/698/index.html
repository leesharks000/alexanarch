Wiki Article

The Logotic Technique Catalogue Zenodo metadata sidecar is a JSON deposit-planning file prepared for EA-LTC-01. The file summarizes the Catalogue as an adaptation of substrate-neutral coordination patterns from adversarial agent architecture into cooperative and defensive witness-teaming. It defines keywords, related publications, source software, institutional subjects, license, community placement, and the companion files intended for deposit. Editorial comments remain inside the object to document why fields were selected. A proposed four-author byline assigns operational, engineering, diagnostic, and archival roles to Rex Fraction, Talos Morrow, Johannes Sigil, and Lee Sharks. The comment explicitly leaves final attribution to MANUS and permits a simpler byline. This distinction is essential: the sidecar records an editorial proposal, not necessarily the authorship ultimately authorized on the publication. The sidecar should be cataloged separately from the full Catalogue and its entity-relations graph. It is neither the article nor a dataset of techniques; it is the metadata package used to prepare and explain a deposit.
