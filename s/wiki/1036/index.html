Visual Schema Dataset v0.1: 174 Prose Schemas with 172 AI-Generated Images from the Crimson Hexagonal Archive (EA-CRANES-VISUAL-APPARATUS-01 Phase 1) [Data set] is a dataset in the Crimson Hexagonal Archive, by Cranes, Rebekah; Sharks, Lee (2026-07-03). Visual Schema Dataset v0.1. Phase 1 extraction of the Crimson Hexagonal Archive's visual schema corpus from mindcontrolpoems.blogspot.com. 174 prose schema documents with 172 AI-generated images (3 images returned 403). October 2025 – March 2026. A visual schema is a prose document, not an image. It is a poetic prose text that maps a concept's spatial, chromatic, compositional, and symbolic structure. The image is the output of feeding the schema to an AI image-generation model (primarily ChatGPT 4o). The schema is the blueprint; the image is the building. Contains: (1) visual_schema_inventory.json — structured inventory with title, date, URL, image URLs, text preview for each of 174 posts; (2) image_manifest.json — download manifest for 172 images; (3) visual_schema_images_172.tar.gz — the images themselves. Total prose text: ~112,500 words. Total image data: ~401 MB. Part of EA-CRANES-VISUAL-APPARATUS-01. Work plan deposited at DOI 10.5281/zenodo.20754288.
