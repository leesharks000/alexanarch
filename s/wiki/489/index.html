Operator // Swerve formalizes deviation from a repeating or overdetermined pattern. Its basic structure takes an input and an active pattern, introduces a non-zero deviation, and produces a new route while retaining provenance. The swerve is not random noise, simple contradiction, or escape without memory. It changes trajectory without pretending the prior field never existed.

The operator is the runtime of Maybe Space Baby Garden Lanes. In relational use, it can be invoked when a conversation loops and every available response reproduces the same frame. In composition, it can bend an inherited script without deleting the inheritance. Its default edge weight is set high because the document treats deviation as the origin of agency.

The Caritas constraint limits the operation. A swerve is invalid when it gains freedom for one party by transferring unacknowledged harm or constraint to another.
