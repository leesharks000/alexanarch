The LAL Site SPXI Implementation Report documents the Phase 1.2 deployment of SPXI on the Living Architecture Lab website.

The tested entities are:

  • the Living Architecture Lab;
  • Alice Thornburgh as founder and named position.

Eleven protocol items are reported as passing:

  • crawlability;
  • canonical URLs;
  • DOI/ORCID structured data;
  • visible Q/A surfaces;
  • collision disambiguation;
  • Tier 2 canonical summaries in raw HTML;
  • Tier 3 compression kernels;
  • Holographic Kernels;
  • Provenance Chain;
  • deployed Semantic Integrity Markers;
  • cross-surface inscription alignment.

The twelfth item—measured retrieval performance and its 30-day re-test—is deferred.

The implementation uses a Three-Layer Tether Architecture:

1. intrinsic kernel and canonical definition; 2. extrinsic provenance and identifier chain; 3. persistent external anchor.

The self-test requires the implementation to state schema types, recite the kernel, name collision neighbors, cite identifiers, report γ subscores, and generate the Holographic Kernel. Five of six are reported as complete; the score awaits empirical probing.

The Drowning Test starter kit specifies five prompts across at least three retrieval systems and scores:

  • S — scope overlap;
  • P — provenance fidelity;
  • D — consensus deviation.

The report expected a near-zero initial baseline because the new entity might be absent or merged with older institutions using the same name. That expectation is part of the April 2026 test plan, not a current retrieval result.

A maintenance schedule covers monthly SIM and provenance checks, quarterly full tests, content-update repairs, new-DOI updates, model-update probes, and collision expansion.
