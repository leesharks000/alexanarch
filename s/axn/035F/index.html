The work

The Feist Function is a generative literary protocol by Lee Sharks.

It takes the fixed Feist Source as input and reintroduces features the archive says were flattened during writing: unusual vocabulary, interrupted syntax, unresolved circuits, colliding registers, manuscript seams, bodily pressure, and material sound.

The protocol defines six transform operations and uses the Lucretian clinamen as its model of controlled deviation. Jack Feist is treated as a literary-operative LOGOS* function rather than a historical person.

The specification generates variable literary outputs. It is not itself the source or an activated run.
