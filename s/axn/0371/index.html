The work

DOIs ≠ Persistent Identifiers is a draft empirical audit by Lee Sharks of 1,817 DOI strings connected to the Crimson Hexagonal Archive.

On June 22, 2026, the study reports that 946 returned public DataCite metadata and 871 returned HTTP 404. Preserved records were overwhelmingly version DOIs, suggesting a type-correlated process affecting concept records.

The paper calls the loss of public identifying metadata while the DOI string persists identifier severance.

The result concerns observed public API and resolution layers at a particular time. It does not alone establish universal DOI-system failure or irreversible deletion from every internal and external copy.
