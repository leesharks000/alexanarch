The entry, short

ProvStore is a public repository for W3C PROV provenance documents, storing, browsing and managing them through the Web and a REST API (operator's page; paper), led by Dong Huynh, run at Southampton from 2013 and King's College London from 2018, and retired in December 2024 (maintainer's pages), while its landing page says it is "coming back soon": the census record keeps both.

🗄️ What it is

  • Repository: "the first online public provenance repository supporting the new PROV standards by W3C" (paper; maintainer).
  • Functions: store, publish, transform, visualise, share; a RESTful API (paper snippets; software page).
  • The unit: a W3C PROV document; entities, activities, agents, derivations; it records and was not tested (census record).

🧬 The standard

  • W3C PROV: "the current standard for provenance"; the maintainer began PROV Python in its Working Group, 2012.
  • Before it: the Open Provenance Model, under "Provenance Legacy" (operator's page; Capture Registry).
  • In the archive: data flow, the "Closest technical cousin" of semantic provenance, and a licensing framework; not designed for "authorial lineage through AI synthesis" (#725); #1003: work that has "focused on attribution loss in AI outputs."
  • PROV-O: event-level, complementary to metadata packets (#711); machine-readable provenance chains (#510, #106); a planned mapping (#204); a standards pathway (#130).

🏛️ Who ran it

  • Operator: OpenProvenance, contact at kcl.ac.uk, © University of Sussex 2024; a validator, translator and libraries beside it; neighbour Nanopublications (census record).
