The work

The Aperture Atlas is an interactive knowledge graph for the Crimson Hexagonal Archive.

The captured site describes more than eighty-eight nodes and 135 edges across six node classes: infrastructure, surface, entity, identity, document, and platform. “Lost” is represented as a status rather than a node type, allowing a vanished manifestation to remain connected to the graph.

Edges use typed relations, including Wikidata property identifiers where possible. Those relations also function as an editorial queue: the graph can indicate where external knowledge-base edits or supporting citations are needed.

The Atlas includes default, basin, ghost, aperture, and Wikidata-oriented views. It also maps itself as a node and exposes structured data for the application, dataset, terms, FAQs, and provenance.

The current body is a capture of deployed HTML from `surfacemap.org`, not the original repository bundle. It preserves a functioning public surface at one moment but may not include unserved source modules, build configuration, or development history.
