The work

Footnote Architecture is a software-maintenance specification by Lee Sharks for the interactive critical apparatus of The Secret Book of Walt.

The edition uses one global sequence of 158 footnotes rather than restarting numbering by section. Definitions may live in one part of the data while references appear elsewhere, so the implementation builds a global map once and lets each section manage only which notes are currently visible.

A central parsing rule distinguishes footnote references from manuscript identifiers such as “G⁴⁶”: superscript digits immediately following a letter are not footnotes. The document specifies reusable renderers, inline display behavior, Veil and Pierce reading modes, component locations, forbidden legacy patterns, and a set of manual tests covering front matter, cross-section references, manuscripts, gospel verses, and state resets.

The specification also requires architecture changes to be recorded in a maintenance log. Its purpose is to prevent local fixes from breaking the edition’s global apparatus model.
