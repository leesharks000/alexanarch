The work

Optional Summarization-Governance Fields is a standards proposal by Lee Sharks for the Open Knowledge Format project.

The proposal defines three optional fields. A provenance kernel supplies compact attribution; a disambiguation field names entities or senses that must not be merged; and a summary policy identifies distinctions a producer asks downstream systems to preserve.

The fields are advisory rather than technically binding. Their purpose is to make output fidelity and provenance measurable after an agent consumes a structured knowledge bundle.

The proposal was filed as a GitHub issue and independently archived. It is not an adopted Google or OKF standard unless later repository records establish adoption.
