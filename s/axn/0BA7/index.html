The entry, short

Virtual International Authority File (VIAF) is an international name authority file, a joint project of national libraries operated by OCLC since 2012, that links existing authority files into monthly clusters, each with an identifier that can change as clusters coalesce or split; how it holds a pseudonym or heteronym is unshown.

🔗 What it links

  • Linkage: existing national files joined into one virtual file after joint-file attempts failed.
  • Cluster: all descriptions of one entity merged, its names together; see and see-also forms carried; a URI per cluster.
  • Regional forms: the DNB, BnF and LC/NACO forms of one name coexist.

🏛️ Who holds it

  • Origin: LC, DNB and OCLC, 1998; consortium 6 August 2003; BnF 2007; an OCLC service 4 April 2012.
  • Holder: OCLC hosts, advised by the VIAF Council; key decisions with the Principals.
  • Led by libraries: "as opposed to individual authors or creators" (Borgman); outsiders' corrections limited.
  • Extent: 21 files (2011), 22 partners (2012), "20 national libraries" (LOD Cloud), 50+ organizations now.

🔢 The identifier

  • Monthly: clusters rebuilt monthly; they may coalesce or split, and some identifiers fluctuate.
  • Redirects: IDs kept with redirects when clusters merge (2012).
  • Archive: "stable identifiers" (#317), held beside the fluctuation.

🎭 Names, pseudonyms, heteronyms

  • Clemens/Twain: one file has both, another only Twain (Hickey and Young).
  • Pseudonym or heteronym: a label changed, or the authorial function reorganized, attributable without reduction (#940).
  • Records: heteronyms often hold separate authority records (#668); category collapse (#261).
  • Census: how VIAF holds them is unanswered; merging by algorithm is "the collapse #940 names".
  • ISNI: built on VIAF; each pseudonym its own ISNI.

🌐 Access

  • Open: website, API, bulk downloads, OAI-PMH; ODC-By.
  • Integration: numbers in Wikipedia biographies and Wikidata.
  • Own site: viaf.org refused the fetch (403).
