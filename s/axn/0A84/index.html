The dataset

The Crimson Hexagonal Archive dataset is the archive's canonical projection on the Hugging Face Hub (leesharks/crimson-hexagonal-archive). It is built in CI by scripts/build_hf_dataset.py from the archive's own stores: the deposit registry and the seated texts, the Capture Registry, the citation graph, the lexical minting registry, the named-entity and hexagon-seat indexes, and the node, relation and assertion layers. Its releases freeze those source files, so a Hub build can be checked against the state it was built from. The whole archive's tree is released separately as the site (AXN:0A63.SITE).
