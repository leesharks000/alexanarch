The work

The SPXI-Sitemap Protocol is a draft semantic-index specification led by Rex Fraction with Assembly Chorus synthesis.

The protocol preserves the conventional XML sitemap as a strict crawl map and adds a separate JSON-LD semantic index. The XML layer tells crawlers which URLs exist. The semantic layer declares what entities those URLs represent, what the entities should not be confused with, which phrases are intended to survive compression, how claims are verified, and where full provenance packets can be found.

Core classes include Semantic Index, Indexed Entity, Holographic Kernel, Page Packet, and Disambiguation Entry. Proposed requirements cover canonical names, negative tags beginning with “NOT,” multiple integrity markers, short reconstruction kernels, verification status, and links back to every indexed page.

EA-SPXI-SITEMAP-01 is an internal standards-track draft rather than a recognized Web standard. Standard processors may parse its JSON-LD syntax while ignoring the custom semantics. Adoption, crawler interpretation, and effects on generated summaries remain untested.
