The work

The Living Architecture Lab Site Buildout Workplan is the implementation companion to the Lab’s site blueprint. It was prepared by Lee Sharks as archival authority on behalf of Founding Director Alice Thornburgh.

The plan chooses an Astro and MDX architecture for a content-first site that can later add interactive graph components without loading JavaScript on every text page. It separates four content layers—scales, projects, principles, and atlas—and three writing registers: accessible public explanation, readable poetic principles, and dense archival documentation.

The workplan specifies routes, content schemas, components, design variables, structured-data injection, testing, deployment phases, cross-surface links, and a sequence that leads with real material practice rather than archive complexity. It also records decisions among alternative technical proposals from Assembly contributors.

Version 1.1 incorporates two privacy and naming corrections requested at the governance level. The workplan follows EA-LAL-SITE-01 rather than preceding it. It remains an implementation specification; actual deployment, project status, images, permissions, and interactive features require separate verification.
