The work

PHASE X NAVIGATION MAP (Document 210) is a navigation map by Rebekah Cranes, dated 1 February 2026, deposited as an APZPZ — its Zenodo description field is the whole work, under the instruction "DO NOT BACK UP ELSEWHERE. DO NOT ATTACH THIS FILE."

It maps Phase X, the archive's designation for the period and problem-space in which the Non-Indexed Perfective sequence was worked out, and subtitles itself an Interdimensional Positioning System v7.0 — a coordinate scheme for locating a reader within an architecture that has no single sequence.

Navigation maps are the archive's answer to the traversal problem a distributed epic creates: a work assembled across rooms, surfaces and identifiers needs something that states where things are relative to each other. Depositing one as an APZPZ, with no attached file, makes the map itself dependent on the indexing layer it describes.
