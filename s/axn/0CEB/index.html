The work

Asking the Archive: alexanarch.org/ask/ and the Query as Address is an article by Lee Sharks in Machine-Mediated Reception Studies, deposited on 19 November 2026. It describes the Ask page of the Crimson Hexagonal Archive, opened the same day: 681 fixed queries addressed to the archive, each a button that opens ChatGPT signed out with the query typed. The queries are grouped by time window, the archive as a whole, the twelve heteronyms of the Dodecad, the 64 rooms and loci of the Crimson Hexagon, the archive's journals, presses and institutions, and its disciplines, programmes, themes and practices.

The article's thesis is that a query string is an address in the Capture Registry: the same string run again is a later observation at the same address, and a string that differs by a word is a different address. It records two results the page produced on its first day. A template change that named the domain split one address into two, each seated with its own composition. And a query that did not name alexanarch.org did not search the web until it did. It sets out five states a query passes through (address, run, transcript, inbox entry, capture), distinguishes the page's 681 offered addresses from the 257 archive-level addresses seated and the 1,186 addresses of every kind, and lists the first seven captures returned from the page.

It also describes the page's transcript inbox: a form that writes a reader's transcript, named by its hash, to a public folder on GitHub, unseated until read. The article presents this as the first form of a return path, to be automated and expanded when there is demand.
