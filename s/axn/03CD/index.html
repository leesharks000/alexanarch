The work

Crimson Hexagonal Interface v2.0 was a Vite and React source-code release for a public interface to the Crimson Hexagonal Archive.

The captured metadata lists a Three.js three-dimensional hex map, Oracle search, Library trails, TRACE provenance, deposit dashboard, Dodecad registry, H_core viewer, and Assembly governance console.

Version 2.0 reportedly introduced a full visual redesign: a splash sequence of fourteen nested rotating hexagons, a formal design-token system, Crimson Pro and JetBrains Mono typography, a dark-and-gold palette, responsive section and card layouts, hover illumination, and beveled metallic hex materials. Deployment ran through GitHub and Vercel.

The current record does not contain the source code or build files. It preserves the DataCite record for the vanished software manifestation and points to historical repository and deployment locations. It is therefore an inventory witness for a software release, not an executable copy.
