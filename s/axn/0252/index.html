The work

The Concordance Engine v0.1.1 is the Tier B implementation companion to the Logotic Technique Catalogue.

Its purpose is to recover coordination patterns first observed in adversarial agent architectures and redeploy them for cooperative production, critique, revision, verification, defensive provenance, and human override.

The runnable component is the Critique Loop. It coordinates a Critic, Reviser, Verifier, authority interface, substrate wrapper, and provenance record. A mock substrate permits demonstration without credentials; a live mode uses the Anthropic API.

The reported bundle includes:

- runnable Python package; - five calibrated agent system prompts; - eight cooperative and defensive skill specifications; - five middleware specifications; - Neo4j 5.x Cypher schema and standing queries; - deposit, license, hex, and discussion-record templates; - Charter, Plan-State, Citation Plan, and Construction Plan; - sample draft and captured Critique Loop session; - twelve smoke-test invariants.

Every revision is reported with SHA-256 hashes of the pre- and post-revision draft, creating a tamper-evident session chain.

Tier B demonstrates one loop. The following remain specified but non-runnable until Tier C:

- Charter Generator; - Verifier; - Basin Hardening Cycle; - Term Collision Audit; - Profile Integrity Guardian; - Depth-Proof Validator.

The body is explicit about substrate limits. The live loop uses Anthropic only. Multi-provider verification is architecturally anticipated but not implemented, so the release does not yet satisfy its own independent two-source verification ideal.

The license is split: CC BY 4.0 for documentation, methods, prompts, and operative documents; MIT for runnable Python code.
