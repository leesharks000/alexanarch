semanticphysics.org v2.2 source snapshot is an archived website bundle created by Lee Sharks for the Semantic Physics project.

The preserved site contains the public landing page, the full synthesis paper in HTML and PDF, structured metadata, an interactive matrix of twenty frameworks, deployment files, a clean source archive, Git history, and a changelog. The live domain was served separately, while this record functions as an immutable snapshot of the May 15, 2026 release.

The changelog documents several substantive revisions. Earlier claims about prediction timing were narrowed; pre-February works were reclassified as retrodictions; the framework census was tiered; archive technologies were moved to a different scale in the matrix; and the effective transport coefficient became the central bridge between semantic movement and provenance retention.

This record should be cataloged as website source and release history. The companion synthesis paper, formal foundations, and live domain are related but distinct objects. A deployable source bundle demonstrates preservation and reproducibility of the site, not independent scientific confirmation of Semantic Physics.
