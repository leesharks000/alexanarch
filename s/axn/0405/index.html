The work

Record #1017 is a second superseded duplicate witness for the Walt Whitman canon provenance node.

It carries a distinct dead DOI and AXN but the same present Whitman body as #1016. Both pre-registry mints redirect to authoritative record #806.

The body’s matching subject does not make this record authoritative. Canon status, relations, and cross-links should be sourced from the later registry-grounded node. This record preserves the duplicate-mint sequence and demonstrates how multiple historical identifiers can point toward one surviving work.

As with #1016, the registry’s supersession reason incorrectly calls the seated body a replicated Sappho node. The bytes instead contain the Whitman text.
