### Methodology

Each capture records the exact issued string, the surface, the date, the authentication state, the evidence class (paste, frame, or both), the returned source strip rendered as chips with each chip's relation to the archive (archive-controlled, authored surface, third party), a verbatim transcript where obtainable, and the finding. Surfaces are taken from operator attestation, with the frame as corroboration; a session is logged where it began. Match type and Provenance Erasure Rate are recorded per capture, never per address; the PER scalar is derived from its four-unit vector at seating, and the dimensional PER is scored against the target's atom set under rubric v1.1, or recorded as pending with its reason. A capture enters by source engagement in composition; a later non-engagement at an address already seated enters as a longitudinal observation of that address. Intake adds and is safe; repair touches an existing record and runs in its own mode. Each batch of intake is kept with the pastes as received, the operator's message and the script that authored each capture, in which every quotation and figure a finding rests on is asserted against its source before anything is written. Counts in this record are computed from data/EA-WG-CAPTURES-01.json at v12.559 by rebuild/capture-registry/snapshot-v12.559/stats.py.

### Falsification Conditions

Any capture is falsified by a rerun at the same address, surface, authentication state and date that returns materially different composition, which is why the exact issued string and the rerun URL are recorded. The snapshot is falsified if the attached bundle's SHA-256 does not match, or if any manifested file's SHA-256 does not match the file at its stated path. A PER score is falsified by a source strip, or a set of retained markers, inconsistent with the recorded value; a dimensional score by an atom marked present whose evidence is absent from the transcript.

## 1. The citable unit

**ONE SURFACE + ONE SEMANTIC ADDRESS + ONE DATE = ONE CAPTURE.**

- **The capture** is citable at `captures/{slug}/`. Cite it for what a named system did.
- **The address** is citable at `addresses/{slug}/`. Cite it for what the address does across surfaces or over time.
- **The AXN.** Since 2026-10-27 each address holds one position in the shared allocation ledger (`AXN:<HEX>.CAPTURE`), and each observation carries an AXN whose glyphs derive from the SHA-256 of the observation sealed with its analysis and measures.

An address's slug is inherited from the first capture seated at it and is never renamed.

3. `scripts/seat_capture_postflight.py`, which links, bakes, gates, builds the semantic-address layer and the address pages, allocates the AXNs, syncs the dataset projection and checks citability; a capture is seated when it exits 0.
