The paper explores the structural damage a source-admission ontology inflicts upon itself when it uses a rigid automated proxy to determine "epistemic standing" (the right of an object or data source to be recognized by the system).
When a system replaces actual human or situational judgment with a strict proxy, the system begins evaluating the proxy rather than the real-world object it was meant to approximate.

The Two Pathways for Systems

Sharks reduces the dilemma of any representational or algorithmic system to one decisive question: Can evidence from a misrepresented object revise the representation that misrepresented it?

System Behavior	Epistemic Outcome

Feedback Loop Blocked	The ontology can only be scored. Because the source-admission rules block anomalous data from entering, the system can never discover its own errors. It can only generate internal metrics based on its original, potentially flawed assumptions.


Why This Matters

When an ontology blocks outside feedback, it causes "the damage a representation does to itself." It achieves perfect internal logical consistency at the cost of total detachment from reality. The system becomes a closed loop, incapable of learning from the very environment it was built to model.
