You said: is papers with code still activeis papers with code still active

       Yes, Papers with Code is active, but it has undergone a complete transformation and revival.
The original platform—which was acquired by Meta in 2019—was abruptly shut down and sunsetted on July 24, 2025. For a while, the original website went offline and simply redirected users to a static GitHub archive.
However, Hugging Face officially stepped in to revive the platform. A team led by Niels Rogge at Hugging Face completely rebuilt and relaunched the site under a new domain: paperswithcode.co.

Current Status of the Platform

• New Domain and Infrastructure: The platform is fully active at paperswithcode.co. It features paper catalogs, browsable taxonomies, and the iconic state-of-the-art (SOTA) leaderboards.
• Fully Open-Source: Hugging Face recently open-sourced the entire platform codebase under an Apache 2.0 license. The codebase (built on a FastAPI backend and React frontend) is publicly hosted on the Hugging Face Papers with Code GitHub Repository.
• AI-Agent Curation: To keep up with the massive influx of daily machine learning papers, the new platform uses automated workflows and AI agents to parse papers, categorize them, and extract benchmark evaluation results.
• Community-Driven Rebuild: Because the historical data had to be rebuilt from snapshots, the current leaderboard coverage is still growing compared to the massive multi-year dataset of the original site, but it is being actively updated with fresh results from major recent conferences (like ICLR, CVPR, and ICML).
If you are looking for the historical, unedited data dump from the original pre-2025 Meta platform, it is still preserved and frozen on the Papers with Code Archive on GitHub. For active daily tracking of machine learning research paired with implementations, you should use the new paperswithcode.co site.
