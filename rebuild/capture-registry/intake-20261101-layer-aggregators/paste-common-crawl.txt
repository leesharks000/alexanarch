Data Formats
Common Crawl distributes its monthly crawls in three primary file formats:

* WARC (Web Archive): Raw HTTP responses, including full HTML content and headers. [[1](https://www.google.com/goto?url=CAESaAHrOzAVuWJzHK_NhVFInACmMHCfBZxBciAC18-xAa4BA2NZRB0ZSgRprcAXL4rPUNXfKBFcs0m-mayAR6JbwfqANVQiK1135DYh_BvnAT1UDbO0hQgfcW8DJ7pVMrufkwqEfoWLWtkj), [2](https://www.google.com/goto?url=CAESaQHrOzAVAZxP3VM22PTIiAdm7yMs9JmJD6Hr_DmNWge_rSKIZ7ihyM9lTenxKVIx9PALbg6KUy0rFAhjY-IKl2DrwZs_WSeL2RHifctFg3YRBlx9RwinZZGOyKCrAb4zW8sPzcM9G6D_yg)]
* WET (Web Extracted Text): Cleaned plain-text content with HTML and code stripped away. [[1](https://www.google.com/goto?url=CAESaQHrOzAVAZxP3VM22PTIiAdm7yMs9JmJD6Hr_DmNWge_rSKIZ7ihyM9lTenxKVIx9PALbg6KUy0rFAhjY-IKl2DrwZs_WSeL2RHifctFg3YRBlx9RwinZZGOyKCrAb4zW8sPzcM9G6D_yg), [2](https://www.google.com/goto?url=CAESaAHrOzAVuWJzHK_NhVFInACmMHCfBZxBciAC18-xAa4BA2NZRB0ZSgRprcAXL4rPUNXfKBFcs0m-mayAR6JbwfqANVQiK1135DYh_BvnAT1UDbO0hQgfcW8DJ7pVMrufkwqEfoWLWtkj)]
* WAT (Web Archive Transformations): Metadata summaries in JSON format containing link and header details. [[1](https://www.google.com/goto?url=CAESaAHrOzAVuWJzHK_NhVFInACmMHCfBZxBciAC18-xAa4BA2NZRB0ZSgRprcAXL4rPUNXfKBFcs0m-mayAR6JbwfqANVQiK1135DYh_BvnAT1UDbO0hQgfcW8DJ7pVMrufkwqEfoWLWtkj), [2](https://www.google.com/goto?url=CAESaQHrOzAVAZxP3VM22PTIiAdm7yMs9JmJD6Hr_DmNWge_rSKIZ7ihyM9lTenxKVIx9PALbg6KUy0rFAhjY-IKl2DrwZs_WSeL2RHifctFg3YRBlx9RwinZZGOyKCrAb4zW8sPzcM9G6D_yg)]
