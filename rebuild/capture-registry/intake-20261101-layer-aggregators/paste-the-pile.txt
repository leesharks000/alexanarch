You said: The Pile datasetThe Pile dataset

The Pile is an 825 GiB to 886 GB open-source English text dataset created by EleutherAI and released on December 31, 2020, to train large language models (LLMs).

Key Overview

• Size: ~825 GiB compressed (zstandard format) containing roughly 300 billion tokens.
• Composition: Combines 22 diverse sub-datasets across academic, web, prose, and code domains.
• Purpose: Designed to improve cross-domain knowledge, reasoning, and generalization compared to raw web scrapes like Common Crawl.
• Notable Models Trained On It: GPT-Neo, GPT-J, and the Pythia suite by EleutherAI.

The 22 Sub-Datasets

The Pile is split into 22 distinct components spanning various types of human writing and knowledge:
1. Pile-CC (Filtered Common Crawl web text)
2. PubMed Central (Open-access biomedical and life sciences literature)
3. Books3 (Long-form literary text/books)
4. OpenWebText2 (Reddit-linked web text)
5. ArXiv (Scientific preprints in physics, math, computer science, etc.)
6. GitHub (Open-source source code repositories)
7. FreeLaw (Legal opinions and court case filings)
8. Stack Exchange (Q&A community site threads)
9. USPTO Backgrounds (U.S. patent application backgrounds)
10. PubMed Abstracts (Biomedical abstracts)
11. Gutenberg (PG-19) (Public domain literature)
12. OpenSubtitles (Movie and TV subtitle transcripts)
13. Wikipedia (English) (Encyclopedia articles)
14. DM Mathematics (Mathematical problem-solving text)
15. Ubuntu IRC (Technical chat logs)
16. BookCorpus2 (Additional books dataset)
17. EuroParl (European Parliament proceedings)
18. Hacker News (Tech/startup forum discussions)
19. YouTube Subtitles (Transcribed video subtitles)
20. PhilPapers (Philosophy research papers)
21. NIH ExPorter (National Institutes of Health grant awards)
22. Enron Emails (Corporate email correspondence corpus)

Controversies and Evolution

• Copyright Disputes: The dataset encountered copyright challenges regarding specific components like Books3 and subtitles, resulting in content adjustments.
• The Common Pile v0.1: EleutherAI introduced ethical alternatives such as Common Pile v0.1 using licensed text.
