The Alexanarch Identifier (AXN) is a three-layer, content-derived digital identifier used
in the Alexanarch self-governing library archive to securely link a file's location,
meaning, and cryptographic hash. [1, 2]
You can read the full documentation on the Alexanarch Identifiers page. [1]

Structure of an AXN Identifier
An AXN follows this format: AXN:<HEX>.<FAMILY>.<EMOJIS> [1]
●​ Positional Layer: A hex code showing the deposit or database index number
(e.g., AXN:0379).
●​ Semantic Layer: A text label showing the subject family or domain category
(e.g., GENERATIVE or GOVERNANCE).
●​ Cryptographic Layer: A sequence of curated emojis mapped from a local
SHA-256 file hash to prove byte-level authenticity. [1, 2, 3, 4, 5, 6]

Key Features
●​ Sovereign and Decentralized: Minted directly by the author or archive
repository rather than a centralized corporate registry. [1, 2]
●​ Tamper-Evident: If a file's contents change by even a single byte, the
cryptographic hash changes, breaking the validity of the identifier. [1]
●​ Local Verification: Calculations run directly in your browser using local
cryptographic tools without uploading source files to an external server. [1, 2]
