# PLAN-C15: the cc15 coincidence

Frozen before any C15 product. The code is PLAN-C14's with the channel and bin changed (cc 15, bin 958936).

## Question

RESULTS-C14 §3: M4's cc15 nomination (ON0013, bin 958936, 1642.3403 MHz, z 14.5) sits at the same position, in the adjacent coarse channel, as the cc14 burst (bin 958935, 1645.2700 MHz). Is it the same 0.7 s event, and what is its shape?

## Steps

As PLAN-C14: restack cc15, read uncapped z at both predictions, and read per-frame power and the 5.72 kHz wide view in all six scans.

## Reading, fixed now

1. If cc15 holds a burst only at frames 664–665 of ON0013, the event is shared by the two channels. Then:
   - a peak ratio to cc14 that is flat across the cc15 view supports a burst wider than 2.9 MHz;
   - a narrow peak at the same bin, in fixed proportion to cc14's peak, supports an instrumental image.
2. If cc15's excess is at other frames, the two are separate events at one position, and that position is recorded as an instrumental coordinate to test across channels.
3. Anything else is recorded as found.
