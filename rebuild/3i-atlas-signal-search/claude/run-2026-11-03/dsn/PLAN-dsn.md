# Frozen plan: the comet frame in the deep-space downlink band, GBT X band 8397.9–8450.7 MHz (written 2026-11-05 17:35 EST, before any of these data are read)

The band where our own receivers listen for spacecraft, the deep-space allocation 8400–8450 MHz (space-to-Earth), is the most direct expression of that practice. The public Green Bank data of 2025-12-18 include an X-band cadence never searched in the comet frame: scans 0061 (ON), 0062 (OFF), 0063 (ON), 0064 (OFF), 0065 (ON), 0066 (OFF), rawspec .0000.h5, 2.79 Hz × 6.085 s, 49 rows. The ATA's July look at these frequencies bounds only watt-class transmitters (chatgpt/C03-equal-strength-envelope-report-2026-11-05.md); Green Bank is the sensitive instrument here. Does anything stand in the comet's frame in this band above chance?

Data. Procedure. Decision. A channel EXCEEDS if its true ON count exceeds every false frame's and its ON−swap difference exceeds every false frame's (chance about 1/41 per channel). A lead: 3 or more of the 18 exceed (binomial chance about 0.8 percent). One or two: reported, and each held out for a replication test to be frozen before it is read. Order and stopping. blc73 coarse channels 0–13 in index order, then blc72 60–63; run to completion (18 channels); no channel skipped for interference.
