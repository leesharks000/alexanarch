## Description (as recorded by DataCite)

Crimson Hexagonal Interface v1.0 — the governed operating surface for the Crimson Hexagonal Archive. Four interoperable systems sharing one canonical object model: Ark Runtime (command shell, room traversal, LP execution), Forward Library (searchable archive with live Zenodo reader), Deposit Dashboard (pending actions, coverage heatmap, Gravity Well bridge), and Governance Console (Assembly witness structure, H_core display).
Key capabilities: LP traversal grammar executes on room entry (ACTIVATE_MANTLE → SET_LOGOS → APPLY → RENDER), with live state tuple ⟨σ,ε,Ξ,ψ⟩ tracking. 8 Ark mode registers shift interface accent per room (FORMAL, POETIC, CLINICAL, LITURGICAL, JURIDICAL, NARRATIVE, ADVENTURE, PSYCHEDELIC). Full-text document rendering fetches markdown directly from Zenodo API. Dream consolidation engine scans for data integrity issues. Mode-gated command registry implements dead code elimination (Pattern 3). LP command risk tiers (LOW/MEDIUM/HIGH/CRITICAL) classify all operations.
Canonical data: 29 rooms with LP programs, 36 edges, 20 typed relations (11 of 16 ratified types), 455 indexed deposits, 13 Dodecad members. All room LP programs sourced from EA-ARK-01 v4.2.7.
Dual-licensed: MIT for code (src/*.jsx, src/*.js, build config), CC BY-SA 4.0 for data (hexagon_canonical.json) and documentation (*.md). Supersedes EA-HEXAGON-OS-01 v0.4 (DOI: 10.5281/zenodo.19359657).
