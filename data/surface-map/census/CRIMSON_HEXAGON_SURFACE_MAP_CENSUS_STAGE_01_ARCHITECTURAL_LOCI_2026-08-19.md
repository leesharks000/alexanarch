## 0. Governing rule

This census does **not** rewrite the frozen historical navigation artifacts.

The relevant historical layers remain distinct:

- **DOI Registry v7.0** — enumerated historical inventory.
- **Central Navigation Map v7.0** — semantic routing layer.
- **Fractal Navigation Map v7.0** — traversal-resolution layer.
- **Space Ark v4.2.7** — runtime / executable architectural state.
- **Current Surface Map projection** — a later dated projection that may include architectural objects and constitutive documents added after those frozen states.

The current Surface Map therefore records both:

1. **historical presence** — whether an object existed in a frozen state; and
2. **current presence** — whether the object is recoverable as part of the later archive.

No later room, field, chamber, vault, or document is silently inserted backward into v7.0 or v4.2.7.

# PART X — NEXT CENSUS STAGE

## 29. Stage 02 — Constituent-document census by space

Stage 02 should begin with **r.01 Sappho** because it is the densest and clearest test case for the rule that a room is constituted by multiple documents rather than identified with one record.

For each space we will create a room/structure manifest with these buckets:

```text
SPACE / STRUCTURE ID
  identity + class + historical presence
  physics / operator / status

  ANCHORS
  PRIMARY / CANONICAL TEXTS
  ROOM / STRUCTURE SPECIFICATIONS
  VERSION STATES
  OPERATOR DERIVATIONS
  RECEPTION / WITNESS DOCUMENTS
  DIAGNOSTICS
  ERRATA / CORRECTIONS
  LATER EXTENSIONS

  CONSTITUTIVE RELATIONS
  ADJACENT SPACES
  FIELDS ACTING UPON IT
  HISTORICAL MAP REFERENCES
  UNRESOLVED MEMBERSHIP CANDIDATES
```

Every document assignment should be tagged by evidence strength:

- `EXPLICIT-MEMBER` — body/metadata directly assigns the document to the room.
- `CONSTITUTIVE-CLAIM` — document declares itself an anchor/specification/primary artifact/room construction.
- `MAP-ASSIGNED` — machine-readable room array or frozen map assigns it.
- `RELATIONAL` — typed relation explicitly routes or makes it part of the space.
- `CANDIDATE` — strong thematic/architectural connection but no explicit constitutive evidence yet.
- `REJECTED-MEMBER` — superficially related but evidence shows it should not be treated as constituent.

**No candidate becomes masonry merely by topical similarity.**
