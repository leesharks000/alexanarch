# Slavonic Josephus — Documented Negative Search (2026-08-19)
Per EA-OMEGA-BUILD-01's ruling: before the contested-pericope resolution, the open
corners were searched for a machine-readable, openly licensed Church Slavonic text of
the recension. Results, with queries as run:

1. GitHub repository search, q="slavonic josephus" — 0 repositories.
2. GitHub code search, q="О пленении Иерусалима" (the recension's Slavonic title) —
   3 code hits, all chronicle-adjacent mentions; no text corpus.
3. PerseusDL canonical-*Lit, First1KGreek, papyri/idp.data — out of scope by design
   (Greek/Latin/papyrological); no Slavonic holdings.
4. archive.org, q=berendts zeugnisse christentum and creator:Berendts — 12 items by
   the author; the 1906 *Die Zeugnisse vom Christentum im slavischen "De bello
   judaico"* (the public-domain German rendering of the eight passages) is NOT among
   the scanned holdings surfaced.
5. koine-greek-corpus, LXX-Swete, Nestle1904, morphhb — Greek/Hebrew only.

CONCLUSION: no openly licensed machine-readable text of the Slavonic recension exists
in the searched corners. The seat proceeds as ruled: a curated contested-status
pericope INDEX with per-passage provenance (this directory), texts to be seated when a
public-domain witness (Berendts 1906 scan, or manuscript digitization) becomes
fetchable. The modern critical texts (Meshcherskii 1958; Leeming & Leeming 2003) are
in copyright and are cited, not seated.
